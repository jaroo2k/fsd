# 로고 시안 — 2026-11-06

| 시안 | 의미 | 선택 |
| --- | --- | --- |
| 01 Document to Run | 접힌 문서와 실행 삼각형: 문서가 개발 실행으로 이어짐 | 최종안 |
| 02 Code Flow | 코드 괄호와 슬래시: 개발 도구의 정체성 | 대안 |
| 03 Run Orbit | 순환 화살표와 실행 삼각형: 반복 작업과 자동화 | 대안 |

1안은 노션 문서에서 작업을 실행하는 제품의 역할을 가장 직접적으로 나타냅니다.
기존 문자 N을 대체하고, 공통 헤더와 파비콘에 적용했습니다.
헤더는 테마의 강조색을 상속하며 모바일에서는 기존처럼 이름을 숨겨도 홈 링크의 접근 가능한 이름을 유지합니다.

각 SVG는 편집 가능한 원본이며 PNG는 노션에 첨부하는 비교용 이미지입니다.
`assets/logo.svg`는 최종안 원본과 같으며 서버에서 인라인으로 삽입하므로 이미지 요청이나 외부 서비스에 의존하지 않습니다.
Docker 이미지에도 assets 폴더를 포함합니다.

PNG 제작에 사용한 공개 QuickChart 렌더링 URL은 previews.json에 보관합니다.
노션에는 해당 URL을 외부 이미지 블록으로 첨부합니다. 이 미리보기는 외부 서비스의 가용성에 의존하며 로컬 PNG도 함께 보존합니다.
재생성은 저장소 루트에서 `python3 docs/logo-concepts/create.py`로 수행합니다(Python 표준 라이브러리만 사용, 인터넷 필요).
곡선은 PNG에서 짧은 직선으로 근사하며 실제 사이트는 SVG 원본을 사용합니다.

요청에 따라 테스트 실행, 테스트 작성, 브라우저 및 Docker 동작 확인은 하지 않았습니다.
